Self-study course · Syllabus v1 · October 2026

AI Transformation with Claude

A technical, hands-on path from Claude power user to independent AI transformation consultant for small and mid-size companies. Every module ends with something you build and can show to a client.

12 weeks8–10 h / weekPython-first12 portfolio deliverables1 capstone engagement

Who this is for and what you leave with

Written for one learner: a data scientist and Python developer who already runs an IT services company and wants to sell AI transformation work. The course skips ML fundamentals and spends the time on three things clients actually pay for: finding the right use cases, building reliable Claude-based systems quickly, and proving the value afterwards.

Technical outcomes

  • Design Claude solutions across apps, Claude Code, the API and the Agent SDK
  • Build and ship MCP servers that connect Claude to client systems
  • Write Skills and plugins that package a company's know-how
  • Run evals, cost routing and guardrails in production

Business outcomes

  • A repeatable AI readiness audit you can sell as a fixed-price entry offer
  • Proposal, SOW and ROI templates
  • A public portfolio of 12 working demos plus a case study
  • A positioning statement and outreach plan for Israeli SMBs

The Claude product map

Most SMB work is picking the lowest layer that solves the problem. Start at the top; go down only when you need more control.

Week 1

The AI transformation landscape

What "AI transformation" means for a 10–200 person company, where the money is, and how Anthropic's products are positioned against the alternatives.

  • Model families (Opus, Sonnet, Haiku) and how to choose by task, latency and cost
  • Augmentation versus automation; reading the Anthropic Economic Index for task-level evidence
  • Data privacy, retention and plan types (Pro, Team, Enterprise, API) as they matter to a client

Week 2

Prompt and context engineering

The core craft. Structured prompts, examples, XML tags, system prompts, long context, and how Projects and memory change what you put in each message.

  • Prompt patterns: role, task, constraints, examples, output format
  • Context engineering: what goes in the Project, the Skill, the prompt, or a tool
  • Extended thinking and when it pays off

Lab: build a prompt library of 15 reusable business prompts (sales, finance, HR, ops) with test inputs and expected outputs.

Week 3

Claude apps for knowledge work

Most clients start here. Learn to deploy Claude to a team so it is used daily, not tried once.

  • Projects as team knowledge bases; artifacts, Docs, Slides, Sheets and dashboards
  • Connectors (Google Workspace, Microsoft 365, Atlassian, Slack) and research
  • Claude in Chrome and scheduled tasks for recurring work
  • Rollout playbook: champions, training, usage reviews
Team planconnectorsChromescheduled tasks

Part 2 · Building with Claude

weeks 4–8
4
Week 4

Claude API in Python

The platform layer. Everything later is built on these calls.

  • Messages API, streaming, structured outputs, vision and PDF input
  • Tool use (function calling) and the manual tool loop
  • Prompt caching and the Batch API for cost control
  • Error handling, retries, rate limits, logging
anthropic SDKtool useprompt cachingbatches
Lab: an invoice and receipt extractor (PDF → validated JSON → CSV) that runs 500 documents through the Batch API and reports cost per document.
5
Week 5

Knowledge retrieval (RAG) for company documents

The most requested SMB use case: "ask our documents". Learn when long context is enough and when you need retrieval.

  • Chunking, embeddings, hybrid search, contextual retrieval
  • Citations and grounding to cut hallucinations
  • Hebrew and Russian documents: tokenisation and search quality
APIcitationsvector DB
Lab: a bilingual (Hebrew/English) policy assistant over 200 pages of HR and procedures, with cited answers.
6
Week 6

Model Context Protocol (MCP)

MCP is how you plug Claude into a client's systems once, and reuse that connection across apps, Claude Code and agents. This is a strong consulting differentiator.

  • MCP concepts: servers, tools, resources, prompts; local versus remote servers
  • Writing a Python MCP server (FastMCP), auth, permissions, read versus write tools
  • Publishing as a custom connector; security review checklist
MCPFastMCPcustom connectors
Lab: an MCP server for a public Israeli data source or a small CRM, used from the Claude app and from Claude Code.

Week 7

Claude Code as a delivery engine

Use Claude Code to build client solutions several times faster, and teach clients' developers to do the same.

  • CLAUDE.md, project memory, slash commands, hooks, subagents
  • Plan → implement → test loops; orchestrating cheaper models for sub-tasks
  • GitHub workflows, code review, CI integration
Claude CodesubagentshooksGitHub

Week 8

Agents, Skills and plugins

From assistants to systems that complete multi-step work on their own, packaged so the client can keep using them after you leave.

  • Claude Agent SDK and Managed Agents; when an agent is the wrong answer

  • Human-in-the-loop approvals for anything that sends, pays or deletes
